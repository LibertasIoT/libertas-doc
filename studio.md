# Libertas Studio

The VS Code extension for building, deploying and publishing Libertas Apps.

**[Libertas Studio](https://marketplace.visualstudio.com/items?itemName=libertas-ai.libertas-vscode)**
on the Visual Studio Marketplace, extension ID `libertas-ai.libertas-vscode`.

## Major commands

Run them from the Command Palette (`Ctrl+Shift+P`, or `Cmd+Shift+P` on macOS).

| Command | What it does |
| --- | --- |
| [Libertas: Manage Hubs](guides/studio.md#managing-libertas-hubs) | Add a Hub, test its connection or remove it. |
| [Libertas: Create New Project](guides/developing-apps.md) | Start a new App project. |
| [Libertas: Deploy to a Hub](guides/studio.md#deploying-to-a-hub) | Deploy the App and its dependencies to a Hub. |
| [Libertas: Monitor Hub](guides/studio.md#logs-and-source-editing) | Stream the Hub's execution logs. |
| [Libertas: Open Admin Panel](guides/administration.md) | Administer a Hub: devices, tasks, users, access and AI connectors. |
| [Libertas: Open Control Panel](guides/control.md) | Operate tasks through their controls. |
| [Libertas: Translate](guides/translation.md) | Translate the App's texts into other languages. |
| [Libertas: Open Libertas Plaza](guides/plaza.md#developer-account-and-repository) | Set up your Plaza developer account. |
| [Libertas: Publish to Plaza](guides/plaza.md#publish-a-deployed-app) | Publish a deployed App. |
| [Libertas: Configure Studio MCP for Codex / for Claude Code](guides/studio.md#using-studio-mcp-with-codex-or-claude-code) | Give your coding agent Studio's tools: compile, preview, deploy and QA. |
