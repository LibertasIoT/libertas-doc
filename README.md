# Libertas documentation

This is the canonical public documentation for Libertas:
[LibertasIoT/libertas-doc](https://github.com/LibertasIoT/libertas-doc).
The current release is **Beta 2**; see [Try Libertas](guides/try-libertas.md).

Start with the [principles](principles.md) and [documentation home](index.md).
The [guides](guides/index.md), [concepts](concepts/index.md),
[examples](examples/index.md), and [reference](reference/index.md) explain
developing Apps and operating a Hub.

AI assistants start at one of these entries:

- [CODEBOT.md](CODEBOT.md): build or change an App.
- [DEVELOPER-ASSISTANT.md](DEVELOPER-ASSISTANT.md): answer App development questions.
- [USER-ASSISTANT.md](USER-ASSISTANT.md): answer Hub owner and App user questions.

[TypeScript support is under development and not release ready](reference/languages/typescript.md#development-status).

The Rust SDK contains runtime APIs and links here for authoring documentation;
it does not publish another copy of these guides and contracts. Clone this
repository for offline documentation; it carries the current edition only. Runtime API details belong to the SDK version in use.
