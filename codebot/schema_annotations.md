# Libertas schema annotations: compact codebot inventory

Use only the canonical source forms below. The parser owns native spelling and
extraction; Studio owns portable placement, host-type, value, conflict, and
compatibility validation. The table is exhaustive for App source, but each
linked canonical section remains the detailed contract. Rule ids in the
effect column name the generated rules on the task cards: the
[data model card](data_model.md) and the cards each row links.

Declare semantic attributes instead of adding AI encoding instructions to
comments: AI Import and the Hub generate [value-representation hints](../reference/llm-document-transformation.md#value-representation-hints)
and send declared [answer labels](../reference/documentation.md#answer-labels-in-ai-descriptions)
(`annot.comments-domain-meaning`).

`—` means that the language has no corresponding source annotation. SDK
serialization derives and runtime functions are outside this inventory.

List declarations use the [positional item divider](../reference/annotations.md#list-item-annotations):
all annotations and documentation after `----` belong to the item. Put List
constraints before it; item constraints after it.
